## 📖 游戏简介

2099 年，赛博城。你继承了一间 24 小时营业的便利店。

白天招待普通市民和加班族，深夜则会有服务机器人、外星旅客甚至神秘黑客光顾。你要做的是：**进货、定价、补货、留住顾客**，把这家小店经营成赛博城的传奇。

### 核心循环

```
进货补货 → 设定售价 → 顾客进店选购 → 收银结账 → 资金增长 → 升级店铺 / 解锁新商品
```

## 🕹️ 操作说明

### 界面按钮（底部）

| 按钮 | 功能 |
|------|------|
| 📦 库存 | 查看库存、进货（+5 / +10）、修改售价 |
| ⬆️ 升级 | 购买店铺升级，解锁更多货架与设施 |
| 📊 统计 | 查看经营数据与成就进度 |
| ⏸️ 暂停 | 暂停 / 继续游戏 |

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 暂停 / 继续 |
| `I` | 打开库存面板 |
| `U` | 打开升级面板 |
| `S` | 打开统计面板 |
| `+` / `=` | 提高游戏速度 |
| `-` / `_` | 降低游戏速度 |
| `1` | 恢复正常速度 |

### 上手建议

1. 开局资金 **¥1000**，初始有 4 种商品各 10 份库存。
2. 先点「库存」，把价格调到成本价附近（如合成拉面成本 ¥5，可先卖 ¥6~8），顾客满意度高会加声誉。
3. 注意补货——缺货会让顾客白跑一趟，影响口碑。
4. 声誉累积到一定程度会提升店铺等级，自动解锁新商品。
5. 顾客有耐心值，让他们等太久会生气离开并扣声誉。

## 🏪 游戏内容

**商品**：合成拉面、机械汉堡、纳米饭团、霓虹可乐、醒神咖啡、超频能量饮、量子电池、记忆芯片、简易义体、外星零食、幸运符咒、时间胶囊（共 12 种，按店铺等级逐步解锁）

**顾客**：普通市民、加班族、服务机器人、外星旅客、神秘黑客、赛博猫咪（各有不同预算、耐心与偏好品类）

**昼夜循环**：上午 → 下午 → 傍晚 → 夜晚 → 深夜，共 5 个时段，不同时段出没的顾客类型不同

**随机事件**：客流高峰、网红效应、慷慨小费、好评如潮、停电事故、偷窃事件、价格战、差评危机、神秘来客、外星交易、幸运之日等 13 种

**升级**：扩展货架、霓虹招牌、空调系统、自动收银机、安保机器人、VIP 休息室、传送门装置等 8 项

**成就**：开张大吉、百笔交易、小有积蓄、富甲一方、商品大师、夜猫子、外星之友、机器人伙伴、猫咪之友、事件幸存者、一周营业等 12 个

**结局**：4 种结局（富豪 / 网红店铺 / 星际贸易站 / 完美结局）

**其他**：localStorage 自动存档（每 30 秒）、纯 Web Audio 合成音效（无外部音频文件）

## 🛠️ 技术说明

- **纯前端**：HTML + CSS + 原生 JavaScript（ES6 Class），无框架、无构建步骤、无依赖
- **渲染**：Canvas 2D 手绘像素图形，无外部图片资源
- **音效**：Web Audio API 实时合成，无音频文件
- **存档**：浏览器 localStorage
- **代码规模**：约 2800 行 JS，12 个模块文件

### 本地运行

直接用浏览器打开 `index.html` 即可。若需本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 仍存在的已知问题

1. **移动端为触控适配，未做竖屏专属布局**
   竖屏下画布按 2:1 比例完整显示，但画面内容仍按桌面版 800×400 场景排布，小屏上元素偏小。横屏体验更佳，竖屏下会显示旋转引导提示。

2. **音效需首次交互后启用**
   受浏览器自动播放策略限制，需先点击页面任意位置。属平台限制，非程序问题。

3. **长局后期数值膨胀**
   资金与声誉无上限，长时间经营后升级全部买满会缺少新的成长目标（15 天结算可规避）。

## 📱 移动端支持

已完成移动端与触屏适配：

- 视口使用 `100dvh`，兼容移动端浏览器地址栏伸缩
- 画布自动扣除 HUD 与按钮栏高度，**不溢出、不产生页面滚动**
- 按钮触控目标 36~44px，符合触控可用性
- 商品卡片在窄屏自动改为纵向排列，操作按钮不挤压
- 输入框字号 16px，避免 iOS 聚焦时自动放大
- 触摸点击画布坐标换算正确，可正常点选货架与顾客
- 已针对窄屏（≤600px）、超窄屏（≤380px）、横屏、触摸设备分别优化
- 竖屏下会在画布下方显示「横屏游玩体验更佳」引导条，横屏与桌面自动隐藏

**实测覆盖**：iPhone 12（390×844）、iPhone SE（375×667）、横屏（844×390）、小屏（360×640）、平板（768×1024），共 53 项检查全部通过。

> 建议：手机上**横屏游玩**体验最佳。
